Hold a value, step up by one, then hold the next one for longer. Every dial here moves on that shape: value 1 covers doors 1..N, value 2 the next N+1, value 3 the next N+2. The bands widen, so each new number gets more room than the one before it — the opposite of a curve that compounds, and the reason the old rule had a cliff at door 5.

The four are on four different schedules on purpose. "More rooms", "more bodies", "more of them at once" and "they shoot sooner" must never arrive on the same door: one change per step is the idea.

Bullet speed is a staircase, not a slope. It holds a value for several doors, steps up, and holds the next one — nobody acclimatises to a number that never sits still. The staircase also decides when the power arrives: slow time is unlocked by the speed reaching a threshold, not by a door number somebody typed, and the blue rows are the school that follows it.
